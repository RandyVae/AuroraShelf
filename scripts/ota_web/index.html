Android 安装提示：
• 点击上方按钮下载最新安装包（Netgrey-v2.19.1.apk）；若浏览器弹窗提示「是否重新下载文件？」，请点击 「再次下载 / 下载」，切勿直接点击旧缓存文件。
• 请勿在微信 / QQ 内直接下载安装，请点右上角 ··· 选择 「在浏览器中打开」（推荐 Chrome 或系统浏览器）。
• 提示「未安装应用」或「签名不一致」时：v2.17.2 起启用正式 Release 数字签名；若手机内已安装旧版（含安全文件夹 / 应用双开内），请先彻底卸载旧版 Netgrey，刷新本页重新下载后再安装，后续版本均可直接覆盖升级。
• 三星手机（One UI）若跳转「安装未知应用」或无法安装：请先进入 设置 > 安全和隐私 > 自动阻止程序 将其关闭；并在「安装未知应用」列表里找到当前使用的浏览器或系统 「我的文件」 打开右侧开关（未安装前列表里不会显示 Netgrey）。
• 若浏览器或 Play 保护机制弹窗拦截，点击 「仍然下载 / 更多详情 > 仍要安装」 即可。
