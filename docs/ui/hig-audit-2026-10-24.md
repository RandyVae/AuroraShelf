- 审查日期：2026-10-24
- 审查对象：`app/` 源码 + Debug 构建（`versionCode 136`，build type debug）+ Release 候选构建
- 平台与设备：Android 14（API 34）/ `missavtest` AVD / arm64-v8a / 1080 × 2340 / density 440 / 竖屏 + 横屏 / 触控输入
- 外观：跟随系统浅色、深色；API 31+ 使用 Material You 动态色，API 26–30 使用回退色板
- 语言：zh-CN；网络：真实网络（内容来自真实来源）
- 依据：Apple HIG（design / accessibility / typography / color / tab bars / sidebars / buttons / layout），
  HIG→Material 3 映射见 `references/13-android-mapping.md`；项目基线 `docs/ui/design-system.md`、`docs/ui/visual-qa.md`

## 判定

- **Apple HIG 对齐度：accept with P2–P3 follow-up**
- **Android 原生一致性：accept with P2–P3 follow-up**
- 说明：这不是“Apple 官方认证”；Apple 不对 Android 应用认证。无未关闭 P0；本次修复 2 个 P1 对比度/字号缺陷。

## 未达标项（强制声明）

| 编号 | 条目 | 原因 | 替代方案 / 影响 |
|---|---|---|---|
| A4/G2 | 无 light/dark/increased-contrast 三态中的 increased-contrast 变体 | Android 37 SDK 未提供可查询“高对比文字”的公开 API（`AccessibilityManager` 无相关方法，`Settings.Secure` 无公开常量）；实现只能靠私有设置字符串，不可靠 | 已保证回退色板关键配对 ≥4.5:1、动态色由系统 Material You 生成；U 盘/系统级高对比仍由 OS 着色。后续若 Android 暴露 API 再补 |
| A7 | 深色模式下白底封面图未压暗 | 封面来自第三方，处理所有图片需额外解码/色彩管线，当前无性能预算证据 | 仅特定来源白底图可能偏亮；未做自动压暗。列为 P3 |
| C3 | 200% 字体下部分卡片元信息换行不美观（如“人观看”拆行） | 允许换行是 HIG/Android 推荐策略，但未做逐卡片排版微调 | 已保证不截断、不重叠；列为 P3 |
| G3/G12 | TalkBack / Switch Control 未逐屏人工实测 | 模拟器需人工交互审查，本轮为脚本截图审计 | 已静态核对主要 contentDescription；正式发布前需人工 TalkBack 走查 |
| G5 | 外部视频源的字幕/音频描述不可控 | 内容来自第三方站点，应用不生成字幕 | 播放器保留系统/站点能力；不承诺字幕覆盖 |
| A9 | 宽色域/Display P3 未涉及 | 应用内无自绘位图资源（均来自网络） | 图片色彩由 Coil 与源站决定，标 n/a |
| 动态色 | 动态色对比度取决于用户壁纸 | Material You 由系统生成调色板，非应用可控 | 已固定所有“固定黑底”场景为固定高对比前景；动态色场景依赖系统 tone 配对 |

## 未验证 / 残余风险

- 播放器错误态、断网态、空分区态的截图未全部取得（网络与时间限制）。
- 60/120Hz 流畅度、长列表内存、真实 Siri/TalkBack 手势未测。
- 项目既有 `docs/ui/design-system.md` 禁止“伪造 blur/Liquid Glass”，而产品实际使用 Backdrop 绘制玻璃浮栏；该规范冲突仍未裁决，本轮沿用既有实现并在此显式记录（见 `.ai/DECISIONS.md`）。
- 证据等级 E3 仅代表此模拟器配置，不代表真机与其它 OEM 表现。
