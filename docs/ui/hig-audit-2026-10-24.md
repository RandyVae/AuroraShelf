- 审查日期：2026-10-24（第二轮：补齐未达标项）
- 审查对象：`app/` 源码 + Release 候选构建 `137`（versionCode 137 / versionName 2.15.0）
- 平台与设备：Android 14（API 34）模拟器 `test`（1080 × 2400 / 420 dpi）与 `missavtest`（1080 × 2340 / 440 dpi），竖屏 + 横屏，触控输入
- 外观：跟随系统浅色 / 深色；API 31+ Material You 动态色；API 26–30 回退色板；**新增高对比（Increase Contrast）色板**

- 依据：Apple HIG（color / accessibility / typography / layout / tab bars / buttons），

## 未验证 / 残余风险

- 播放器错误态、断网态、空分区态的截图未全部取得（网络与时间限制）。
- 60/120 Hz 流畅度、长列表内存、真实 TalkBack/Switch Control 未测。
- `docs/ui/design-system.md` 禁止“伪造 blur/Liquid Glass”，而产品实际用 Backdrop 绘制玻璃浮栏；规范冲突仍未裁决，本轮沿用既有实现并记录（`.ai/DECISIONS.md`）。
- 高对比色板只验证了 AOSP `Settings.Secure.high_text_contrast_enabled` 路径；API ≥36 官方 API 分支由 compileSdk 37 编译通过但模拟器为 API 34，未在 API 36+ 设备实测。
- E3 仅代表本模拟器配置，不代表真机与其它 OEM。

## 开屏动画（140，新增）

用户要求加入 Netflix 式片头动画。判定：**可以做，但不照搬**——Netflix 片头约 4 s、不可跳过且带音效，直接照搬会违反 HIG F3（动画必须可跳过）与 G8（避免自动播放声音）。实现为原创动画：

| 项 | 决定 |
|---|---|
| 内容 | 纯黑舞台 + 三条光带写出的原创 "N"（品牌冷灰 #9AA3AE）+ 对角线光扫 + 字标 letter-spacing 展开；无第三方标识/音效 |
| 时长 | 完整时间线 **1.9 s**，结束后 120 ms 淡出；远短于片头式 4 s |
| 可跳过 | 点击任意位置、或按返回键立即淡出；无障碍标签「Netgrey 品牌开场，点按跳过」 |
| Reduce Motion | `ValueAnimator.areAnimatorsEnabled()` 为 false 时**不做位移/绘制动画**，静态显示完整标志 0.7 s 后淡出（G7/F5） |
| 声音 | 无（G8；且不假设设备音量/静音状态） |
| 启动延迟 | 动画以 overlay 覆盖在**已经组合并开始加载的 App 之上**，不阻塞首屏请求；系统 splash 之后播放，点击可立刻进入 |
| 颜色 | 专用开场 token（IntroBackground/Mark/Wordmark）；对比度：字标 21:1、标志 8.22:1、跳过提示 ≥5.9:1 |
| 测试影响 | `BuildConfig.DEBUG` 时跳过动画，instrumented 测试不会被全屏遮罩阻塞；release 真机/模拟器验证 |
| 证据 | E3：`docs/screenshots/launch-intro-2026-10-24.png`、`launch-intro-reduced-motion-2026-10-24.png`；本地录屏 `captures/launch-intro-140.mp4` |

未达标/限制：
- 动画本身是**品牌表达、非功能信息**，HIG F1 要求动效有信息含义；此处按"启动品牌时刻"定位，属可选的品牌表达，用户可跳过且不承载状态信息，因此不用于传达任何必要信息。
- 系统 Android 12+ splash screen 会先于本动画出现（不可定制时长），两者叠加会让冷启动"看到品牌"的时间变长；介意时可在系统层把 `windowSplashScreenAnimatedIcon` 收敛，但当前保留默认。
- 未做 TalkBack 实际语音走查（标签已提供，属人工验收项）。
- 未做音效（如需要可后续单独评估，默认不加）。
