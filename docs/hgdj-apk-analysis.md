# 黄果短剧 APK 静态分析

分析对象：`hgdj_1.1.0_260906_1.apk`（用户提供，仅作兼容性参考）。

## 结论

- 包名为 `top.wzbwg.homieo`，版本 `1.1.0`，主界面由 Flutter 构建，包含 Android Media3/IJK 播放相关组件。
- 内容接口覆盖短剧首页、短剧列表、排行榜、搜索、详情和选集；播放数据使用 HLS m3u8，部分地址在网页/接口数据中动态刷新或加密。
- APK 还包含登录、关注、评论、点赞、收藏同步、会员、金币、购买、下载缓存、AI 内容制作等商业或账号功能。

## 本工程采用的合并范围

当前 `AuroraShelf` 只合并与无账号内容消费直接相关的能力：

- 服务端 HTML 列表解析、封面/标题提取和分页加载。
- 黄果站点的 `/detail/...` 详情链接、`/newest/2/` 与排行榜分页路径。
- 从播放页 `data-play-src`、`videoInitialData`、JSON-LD 或标准 `<video>/<source>` 中读取 MP4/HLS 地址。
- 使用 Media3 播放，并携带详情/播放页 Referer。
- 本地收藏、观看历史、搜索已加载内容和站点设置。

以下能力明确不合并：登录/注册、会员、金币、支付/购买、下载缓存、评论/点赞/关注、AI 制作和账号云同步。这样两个 APP 可以保持独立，也不会把账户或商业接口耦合进纯浏览播放客户端。

## 兼容边界

黄果站点当前页面可以被本工程直接适配，但播放地址带有时效签名，必须在播放时重新请求页面；如果站点启用登录、验证码、DRM 或改变数据字段，需要再次调整适配器。未从 APK 复制其 Flutter AOT 二进制、密钥、加密配置或商业接口实现。
