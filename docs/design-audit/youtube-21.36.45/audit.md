## 参考与边界

- XAPK 已拆分核对，基础包为 `com.google.android.youtube`，版本 `21.36.45`，包含 arm64、xxxhdpi 和语言资源分包。
- 测试镜像预装了另一签名的 YouTube 系统应用，参考 XAPK 因签名冲突无法覆盖安装；系统版启动后又被强制更新页阻断，因此没有把该页面冒充为信息流视觉证据。
- 本轮视觉目标以用户明确给出的结构为准：首个视频占据大幅区域，后续视频每行两个并持续向下排列。

## GitHub 调研

在 GitHub 搜索 Compose 视频项目时，没有找到星标超过 500 且可直接复用的 YouTube 首页双列组件。较成熟结果包括 `panpf/sketch`（图片/视频缩略图加载，Apache-2.0）和 `GetStream/whatsApp-clone-compose`（Compose 信息流示例，Apache-2.0），但前者会替换现有 Coil 链路，后者的聊天信息架构不适用于本项目。最终不新增依赖，继续使用 Compose `LazyColumn`、稳定键与现有真实封面加载器。

## 实现映射

1. 第一条视频继续使用全宽 `HeroVideoCard`，保持现有推荐入口与沉浸封面。
2. 第二条开始按两个一组生成惰性行；每张卡等宽，列间距 12 dp，页面边距 20 dp。
3. 网格封面使用 16:10 裁切和 16 dp 圆角；标题最多两行，并预留两行高度，使同一行来源信息对齐。
4. 收藏按钮保留 48 dp 触控目标；卡片整体可点击，并沿用现有震动反馈。
5. 分类继续吸顶，列表视口继续延伸到液态玻璃导航后方，尾部留白确保最后一行能完全滚出遮挡。
