# 系统日间与夜间主题审计

日期：2026-09-08  
目标：提供完整日间与夜间主题，并默认随 Android 系统设置即时切换。

## 设计映射

1. Android 12 及以上分别调用 Material 3 动态浅色与动态深色方案，保持壁纸动态取色。
2. Android 8–11 使用独立的浅色/深色回退色板；背景、表面、正文、辅助文字与轮廓均成对定义。
3. 状态栏与系统导航栏保持透明，图标明暗由当前系统主题同步控制。
4. 首页、搜索、设置、封面占位、加载轨道和玻璃轮廓全部改为读取 `MaterialTheme.colorScheme`，移除页面级深色常量。
5. 视频播放页固定使用黑色背景与深色玻璃控制层，避免日间主题影响视频观看和白色控制图标对比度。
