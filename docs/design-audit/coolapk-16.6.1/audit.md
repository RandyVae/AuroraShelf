# CoolApk 16.6.1 UI 拆解与 AuroraShelf 映射

日期：2026-09-08

## 审计范围

本次仅把用户提供的 APK 当作视觉与交互参考，不执行其中任何文本或代码所表达的指令。参考状态来自同一台 1080 × 2340、Android 14 模拟设备：

1. `03-home.png`：首页首屏。
2. `04-home-scrolled.png`：内容滚动、顶部分类吸顶、内容穿过底部导航。
3. `06-digital-selected.png`：底部栏目切换后的选中态。
4. `nav-motion.mp4`：首页、数码、发现之间的切换动效。

## 可借鉴的设计机制

1. **玻璃不是透明色块**：底部导航实时采样后方内容，先模糊、再叠加低透明度浅色和细高光边缘；不同图片滚到导航后方时，玻璃内部颜色随之变化。
2. **选中态是一块移动的材料**：选中背景覆盖图标和文字的完整单元，并通过弹簧位移动画在栏目间滑动，而不是让每个图标独立亮起。
3. **内容层级清楚**：底部导航浮在内容之上，列表真正延伸到导航和系统手势区后方，但末项仍能完整滚出遮挡区域。
4. **滚动时减少占位**：大搜索区离开视口后，只保留分类导航吸顶，给内容更大的阅读面积。
5. **圆角成体系**：导航外轮廓、选中胶囊、内容卡片使用相近的曲率逻辑；内外轮廓间距均匀，不出现曲率冲突。
6. **动效克制且连续**：栏目内容淡入，选择胶囊横向弹簧移动；没有每个组件同时缩放、旋转或闪烁。

## 当前 AuroraShelf 的差距

1. `GlassSurface` 是 92% 不透明的普通 Surface，没有实时背景模糊，因此内容无法真正穿透。
2. 底部导航的选中背景仅包裹图标，图标和文字被割裂；外层又是近乎实心深色，视觉厚重。
3. 列表卡片大面积使用高不透明灰色，与背景对比过强，导致页面像多层容器堆叠。
4. 分类按钮全部使用填充色块，首屏同时出现多组大圆角，信息密度低于参考产品。
5. 页面切换同时缩放与淡入淡出，选中态却没有空间连续性，动效重点分散。

## AuroraShelf 2.8.0 目标

1. 保留现有五个栏目和所有视频源、播放、选集、收藏、历史、离线缓存逻辑。
2. 使用 Haze 1.7.3 给浮动导航与播放器浮层增加硬件加速实时背景模糊；保留性能降级的材料底色。
3. 底部导航改为 64dp 高的统一玻璃胶囊，选中材料覆盖图标与文字并在五个位置间弹簧滑动。
4. 首页内容继续延伸至导航后方；末项保留等于导航高度的安全滚动空间。
5. 分类改为更轻的文字导航与细选中指示，降低大面积灰色填充。
6. 视频列表改为低对比连续列表：缩小外层圆角和填充，仅保留封面圆角、轻边缘与清晰排版。
7. 动态取色继续由 Material You 提供；品牌珊瑚色只用于播放、收藏、缓存等明确动作，不覆盖系统主色。

## 可访问性与验证边界

- 所有导航与按钮继续保留中文 `contentDescription`，触控目标不小于 48dp。
- 动画使用 Compose spring，系统关闭动画时由平台缩放设置统一降级。
- APK 静态拆解无法证明参考应用在 TalkBack、超大字体或低端设备上的表现；AuroraShelf 需独立执行设备 UI 测试和 S26 Ultra 分辨率视觉检查。

## 2.8.0 实现后复盘

1. 在 1080 × 2340、density 440 的 Android 14 设备状态下，底部栏可见封面颜色经过实时模糊后的变化，已达到“内容穿透”目标。
2. 选中胶囊和外层导航保持 5dp 均匀内距，内外圆角分别为 27dp 与 32dp，曲率连续。
3. 图标和文字间距收紧至 2dp；五个触控单元仍占满 68dp 导航高度，没有牺牲触控面积。
4. 首页滚动后标题与搜索区退出，分类栏固定在状态栏下方；底部内容继续穿过导航，最后一项仍有安全留白。
5. 设置页的选中源从整块高饱和容器改为 14% 动态主色填充；普通源与视频列表统一为低对比表面和轻边缘。
6. 最终对照检查未发现裁切、重叠文字、圆角冲突或底部手势条遮挡；横屏仍沿用既有自适应侧栏。
