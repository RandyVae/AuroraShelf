# 2.12.0 设置、来源与二级页面联合审计

日期：2026-09-09
视口：Android 14、1080 × 2340、density 440
目标：按 Material 3 规范提升设置、视频源、漫画源和漫画详情的上线完成度。

## 第一轮发现

- 设置页面背景透明，首页标题、封面和设置内容同时出现，造成严重的层级和可读性问题。
- 十余个视频源直接平铺在设置首页，离线缓存和自定义站点入口被推到长列表底部。
- 漫画源与分类同时使用两排横向 FilterChip，来源数量增加后无法快速判断当前层级和可用状态。
- 漫画详情缺少明确的信息容器和章节触控边界，标题、标签、简介与章节层级偏弱。

## 第一轮调整

- 设置页面使用不透明主题背景，主页面只保留“视频源”和“离线缓存”两个高层入口。
- 视频源迁移到独立二级页，增加搜索、明确的“使用中”状态和聚合的自定义站点表单。
- 漫画源改为单一来源卡与 Material 3 底部选择面板；分类继续使用轻量 FilterChip。
- 漫画详情增加吸顶标题栏、圆角信息卡、主阅读按钮和带序号的章节卡片。

## 第二轮复查与修正

- 发现设置首页两个导航行因容器布局方式错误而重叠；改为纵向容器后重新截图确认。
- 检查日间和夜间动态色：背景、表面、选中态、辅助文字和底部玻璃导航均保持清晰。
- 检查 48 dp 以上触控目标、返回语义、搜索标签、来源选中状态和内容滚动至底栏后方的表现。
- 增加设置二级页、地址错误状态漫画来源面板设备回归，避免结构调整后出现不可达入口。

## 验收边界

模拟器已覆盖默认字体、日间/夜间、滚动、返回和来源选择。三星 One UI 真机的字体栅格、120 Hz 长时间滚动、TalkBack 完整走查和不同壁纸动态色仍需发布前真机验收；源站可用性也可能随地区、证书和网页结构变化。
