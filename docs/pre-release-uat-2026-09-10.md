## 可重复执行

使用 JDK 21 和已连接的 Android 模拟器：

```sh
./gradlew connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=com.aurorashelf.app.PreReleaseSourceAuditTest \
  -Pandroid.testInstrumentationRunnerArguments.sourceAudit=true
```

`auditAllConfiguredSources` 是收集型巡检，逐阶段捕获异常以继续遍历：**Gradle 成功仅表示巡检运行结束，不代表来源验收通过。** 需查看 `PreReleaseAudit` 的 FAIL、计数和 NEEDS_ACCOUNT。论坛列表测试使用断言。

全源日志：`captures/pre-release-20260910/source-audit.log`；设备结果：`captures/pre-release-20260910/source-audit-results/`。这些证据位于本地忽略目录，不随 Git 提交。

上线前须先解决/明确禁用不可用来源，明确直播及分页限制，再补齐实际媒体呈现、论坛多页和离线流程，最后在签名 Release 与真机完成验收。
