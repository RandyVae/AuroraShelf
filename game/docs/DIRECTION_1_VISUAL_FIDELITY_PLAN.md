## 一、主大廳（Main Hub）現狀 vs 線上原版差距矩陣

| 區域 | 線上原版（Unity WebGL 23.0.1）實測特徵 | 本地 Web 目前實作現狀 | 方向 1 改造落地方案 |
|---|---|---|---|
| **螢幕適配與長寬比** | 鎖定 16:9 / 18:9 寬螢幕橫向滿版（寬度 100vw，兩側不留黑邊） | 目前 CSS `.stage` 在非全螢幕桌面被限制於 `min(100vw, 920px)`，造成窄版豎屏感 | **解除 `.stage` 桌面強制窄版限縮**，支援橫屏 16:9 自適應滿版縮放 |
| **中央看板娘（Kitty）** | 佔螢幕高度 85% 以上，支援 Breathing/Idle 呼吸骨骼，並配備動態光暈 | 目前已具備 Spine 骨骼，但在載入失敗時降級為靜態圖 | **優化 Spine 舞臺權重與置中锚點**，確保 Kitty 實體骨骼優先載入並置中偏右 |
| **左上指揮官資訊** | 圓形頭像框 + 等級 Badge（Lv.1）+ 指揮官暱稱 + VIP 徽章 | 方形圓角頭像 + 文字標籤 | **重構為金屬圓環頭像框**，加入 VIP0/VIP1 金色徽章與升級進度條 |
| **頂部資源貨幣條** | 靠右橫排 4 類資源：金幣（Gold）、銀幣（Silver）、鑽石（Gems）、行動力（Energy + 時間倒數） | 頂部 pill 僅有金幣、鑰匙、行動力 | **完全對標 4 連膠囊貨幣條**，帶「+」號充值按鈕樣式與數字滾動格式 |
| **右側核心動作區** | 超大黃橙漸變斜角切邊 **`FIGHT` 戰鬥按鈕**（附帶火焰光效）+ 上方 Captain's Path 征程卡片 + 每日任務卷軸 | 底部 5 宮格平鋪按鈕 | **將「戰役/FIGHT」移至右側作為核心焦點**，製作斜切邊戰鬥按鈕，還原右側視覺重心 |
| **底部導航選單** | 5 大扁平橫向圖標條：Shop（商店）、Heroes（角色/編隊）、Relics（神器/好感）、Clan（軍團）、Settings（設置） | 底部網格排列 | **重構為沉浸式底部金屬浮動選單**，附帶選中高亮光條與新解鎖紅點提示 |
